
#   DESAFIO POO DIO/ACCENTURY 
##  Projeto baseado no repositorio -> https://github.com/cami-la/desafio-poo-dio
##  Melhorias

- **Validação obrigatória de campos**  
  - Campos como `titulo`, `devs` e `descrição` são **non-null**, garantindo integridade dos dados.  
  - Implementado com a classe `Objects` do pacote `java.util`.

- **Sistema de XP dinâmico**  
  - O ganho de experiência (XP) é proporcional à **carga horária** das atividades.  
  - Permite evolução realista dos desenvolvedores cadastrados.

- **Persistência de Devs**  
  - Cadastro de desenvolvedores com **nome** e **ID**.  
  - Dados armazenados de forma persistente para consultas futuras.

- **Coleções imutáveis**  
  - Listas expostas ao usuário são **imutáveis**, garantindo segurança e evitando modificações indevidas.

- **Estrutura de pastas organizada**  
  - Separação clara entre:
    - `dominio` → classes principais e entidades  
    - `servicos` → regras de negócio  
    - `persistencia` → armazenamento e recuperação de dados  

- **Impressão formatada**  
  - Saídas no console são exibidas de forma clara e legível, facilitando a compreensão.
